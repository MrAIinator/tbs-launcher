TBS Launcher — The Broken Script Enhanced
Minecraft 1.21.1 · NeoForge 21.1.249 · сервер 202.181.188.169:25841

КАК ЗАПУСТИТЬ
1. Распакуй архив целиком. Не запускай bat из архива.
2. Дважды нажми «TBS Launcher.bat».
3. «ПРИВЯЗАТЬ» — код с microsoft.com/link, тем Microsoft-аккаунтом, где куплена Minecraft Java.
   Пиратка и оффлайн-ник не пройдут.
4. В «НАСТРОЙКАХ» поставь память (лучше 8–12 ГБ) и разрешение окна, либо полный экран.
5. «ИГРАТЬ». Первый раз качает Java 21, игру, NeoForge и моды. Потом сразу кидает на сервер.

КУДА СТАВИТСЯ ИГРА
%AppData%\TBSLauncher\game
Официальный .minecraft не трогается.

КАК ВЫКЛАДЫВАТЬ ОБНОВЛЕНИЕ СБОРКИ
Лаунчер при каждом старте читает
https://raw.githubusercontent.com/MrAIinator/tbs-launcher/main/manifest.json

1. Собери новый .mrpack (Minecraft 1.21.1, NeoForge 21.1.49 или новее).
2. Замени в репозитории файл pack/pack.mrpack.
3. В manifest.json подними packVersion, например 1.1.0. Адрес сервера тоже меняется там.
4. Уже установленные лаунчеры при следующем «ИГРАТЬ» докачают только изменённые файлы
   и уберут моды, которых больше нет в сборке. Моды, которые игрок положил сам, не трогаются.

КАК ОБНОВИТЬ САМ ЛАУНЧЕР
Собери новый zip, залей его релизом GitHub (тег v1.0.0 или новее, файл TBS-Launcher-win64.zip),
подними launcherVersion в manifest.json. Старый лаунчер скачает zip и применит его
при следующем двойном клике по bat.
